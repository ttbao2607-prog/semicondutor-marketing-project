# Parent review · HTML editorial harness draft

The committed Bao assessment at c38a624 is the requirement anchor, not approval of this implementation. Rejected v2 is retained as a failing regression.

The draft checks exact adopted manifest pins, public locale projection and initial VI DOM, native case identity, complete new detail rows, original/detail source URLs, one metric block, missing details, duplicated prose, numeric additions and common governance phrases. It rejects counterexamples for swapped sources and lost translated detail. Browser review independently compares actual four-locale public fields to the owner release and inspects mobile hierarchy/readability.

Mechanical checks cannot decide whether a source supports a claim, whether prose provides meaningful reading value, or whether visual design suits the audience. Root reviewed those dimensions for this specific demo; Bao still decides its design acceptance. Keyword checks only flag candidates for review and do not prove absence of every kind of internal agent wording.

The executable gate contains a CASE06 regression profile: exact company, eight added claim IDs and four operational rows. These are not universal requirements for other case adapters. Future profiles must derive facts from their own approved sources and final-card promise; never invent functions to fill these slots. General editorial rules are in html-editorial-harness.json. Any future mass rollout requires Bao's demo freeze, adapted source-bound profiles, renewed parent content/render review and explicit ad/adapter pair acceptance.
